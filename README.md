# mirathi-data

بيانات تنزيل تطبيق «ميراثي» (`mahmoudkraizim-dotcom/mirathi`).

## مصاحف الروايات
لكل رواية إصدار باسم `riwayat-v1-<المفتاح>`، فيه أرشيف واحد `<المفتاح>.zip`:

| المفتاح | الرواية |
|---|---|
| `warsh` | ورش عن نافع |
| `qalun` | قالون عن نافع |
| `shuba` | شعبة عن عاصم |
| `duri` | الدوري عن أبي عمرو |

- **المصدر:** مصاحف مجمع الملك فهد لطباعة المصحف الشريف بالمدينة النبوية، عبر archive.org.
- **الصيغة:** أرشيف ZIP بلا ضغط (STORE)، فيه `manifest.json` و`001.webp` إلى `604.webp`، بعرض ٨٠٠ وثلاث درجات رمادية.
- **التحقّق:** حجم كل أرشيف وبصمته (sha256) مسجّلان في فهرس التطبيق، والتطبيق يرفض كل أرشيف لا يطابقهما.
- **الإنتاج:** بأدوات `mirathi-tools` (`gen_riwayat_pages.py` و`pack_riwayat.py`)، وإعادة الحزم تعطي الملف نفسه بايتًا ببايت.

لا تعدّل الملفات يدويًا. كل تغيير يكون إصدارًا جديدًا (`riwayat-v2-…`) مع تحديث الفهرس في التطبيق.
